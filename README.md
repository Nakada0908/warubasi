# オンライン対戦型カードゲーム　カードで対戦！割りばし！ - ソースコード

指遊びである「わりばし」をオンラインマルチ対戦でできるようにし、カード要素を足すことで戦術の幅を広げました。
対戦方式は、合言葉によって相手を特定する合言葉式とランダムで相手を探すマッチング式の二つを用意しました。
基本はクリック、タッチによって操作できるシンプルなものになっています。
